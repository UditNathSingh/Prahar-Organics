## Overview
Prahar Organics is a responsive, multi-page frontend website designed to showcase pure, naturally sourced agricultural products from Jharkhand. This project was developed by translating static PNG design mockups into a fully functional, production-ready website. 

## Features
* **Multi-Page Architecture:** Includes 5 complete pages (Home, About, Products, Our Farms, Contact).
* **Responsive Layout:** Optimized for seamless viewing across desktop, tablet, and mobile devices.
* **Modern UI:** Built utilizing a custom nature-inspired color palette and elegant typography.
* **Secure Hosting:** Deployed via GitHub Pages on a custom domain with forced HTTPS.

## Tech Stack
* **HTML5** for semantic structuring.
* **Tailwind CSS** (via CDN) for rapid, utility-first styling.
* **Google Fonts** (Playfair Display, Inter, Dancing Script) for typography.
* **Git & GitHub** for version control and CI/CD deployment.
